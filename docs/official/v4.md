# Langfuse v4 已上线

Langfuse v4 已在 Langfuse Cloud 上线，并正式支持[自托管部署](https://langfuse.com/self-hosting/upgrade/upgrade-guides/upgrade-v3-to-v4)。它显著加快了大规模项目中表格、仪表盘、API 和评估的运行速度。官方表示，大型项目仪表盘加载速度至少提高 **10 倍**。

v4 的核心是专为 Agent 系统设计、**以 Observation 为中心**的数据模型。现在可以直接查询任意 LLM 调用、工具执行或 Agent 步骤，无须昂贵的跨表关联或查询时去重。

::: info
如果你是 Langfuse 新用户，无需迁移，直接按[入门指南](/official/observability/get-started)操作即可。
:::

## 有哪些新变化？

每个操作都成为可以独立查询的一等对象。可以跨大量 Trace 直接查找慢速 LLM 调用、高成本模型、失败的工具调用或单独的 Agent 步骤。

底层存储使用一张不可变的 Observation 表。同一 `trace_id` 的所有行组成一条 Trace，而 Trace 级属性会复制到各个 Observation 行。

**全产品正在弃用 Trace 级别的输入与输出。** 表格、LLM-as-a-Judge 评估器和导出功能，改为读取相关 Observation（通常是根 Observation 或某次 LLM 调用）的输入与输出。直接选取需要的 Observation，比拼装整条 Trace 更准确，也是 v4 速度提升的重要原因。

这一模型使子 Agent、工具调用和 LLM 调用可以直接查询及评估，同时减少重复更新和读取时的去重开销。

它还支持：

- [全文搜索](/official/observability/features/full-text-search)：搜索输入、输出和元数据；
- [筛选搜索栏](/official/observability/features/filter-search-bar)：快速键盘筛选；
- [指标告警](/official/observability/features/alerts)；
- 更快的 [Observations API v2](/official/api-and-data-platform/features/public-api) 和 [Metrics API v2](/official/metrics/features/metrics-api)。

更多资料见[数据模型](/official/observability/data-model)与[在 v4 中探索 Observation](https://langfuse.com/faq/all/explore-observations-in-v4)。

## 升级时间线与 Cloud 迁移

Cloud 项目可以通过侧边栏的 **Migration Assistant**，或[迁移状态页面](https://cloud.langfuse.com/v4-migration)，检查尚需完成的迁移操作。

官方时间线组件会动态显示最终切换日期，因此这里不填入未经静态核实的日期。请以[官方 v4 页面](https://langfuse.com/docs/v4)为准。

Cloud 发布细节：

- **2026 年 4 月 14 日 14:00 UTC**及以后创建的组织默认使用 v4，不显示切换按钮。
- 更早创建的组织，在 Cloud 完全切换到 v4 前，可以通过界面左下角 **Langfuse v4 preview** 切换。
- **2026 年 5 月 20 日**及之后创建的 Cloud 项目，导出来源固定为“enriched observations”。
- 自 **2026 年 6 月 22 日**起，不再允许创建新的旧版导出集成。

## 如何升级？

参照[逐步升级指南](https://langfuse.com/faq/all/upgrade-to-langfuse-v4)，覆盖 Cloud、直接 API、OpenTelemetry 和自托管用户。

自托管用户需执行[服务端 v3 → v4 升级指南](https://langfuse.com/self-hosting/upgrade/upgrade-guides/upgrade-v3-to-v4)。

使用前检查[SDK 与服务端版本兼容矩阵](https://langfuse.com/docs/compatibility#sdk-server)。

如需讨论发布与迁移问题，可以参与[官方 GitHub Discussion](https://github.com/orgs/langfuse/discussions/12518)。
