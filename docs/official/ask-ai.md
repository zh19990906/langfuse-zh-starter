# 向 AI 提问（Ask AI）

Langfuse AI 助手可以回答有关 Langfuse 功能、集成和最佳实践的问题。该助手基于官方文档、GitHub Discussions、Issues 和 API 参考资料提供回答。

如果你想使用 Langfuse 的交互式示例项目，请访问[官方 Demo](https://langfuse.com/docs/demo)。

同样的文档知识也可以通过 [Langfuse Docs MCP Server](/official/docs-mcp)以编程方式获取。

## 打开 AI 助手

本中文站使用静态 VitePress 页面，不直接运行官方嵌入式聊天组件。可以通过[官方 Ask AI 页面](https://langfuse.com/docs/ask-ai)体验该功能。
