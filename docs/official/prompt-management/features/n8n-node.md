# Langfuse 提示词管理的 n8n 节点

Langfuse n8n 节点可以把[提示词管理](/official/prompt-management/get-started)无缝集成到 n8n 工作流。这是由社区维护的节点，可以在 n8n 中直接读取并使用 Langfuse 项目里的提示词。

> **什么是 n8n？** [n8n](https://github.com/n8n-io/n8n) 是开源、基于节点的工作流自动化平台，可以通过可视化方式连接 API、应用和数据，不必从头编写完整代码。

![n8n 工作流中的 Langfuse 节点](https://langfuse.com/images/docs/prompt-management-node-in-n8n-workflow.png)

::: info
如果你想追踪 n8n 工作流的运行过程，请查阅 [n8n / Langfuse 集成说明](https://langfuse.com/integrations/no-code/n8n)。
:::

## 安装

**自托管 n8n**：打开 **Settings → Community Nodes**，安装包：

[`@langfuse/n8n-nodes-langfuse`](https://www.npmjs.com/package/@langfuse/n8n-nodes-langfuse)

**n8n Cloud**：在工作流中搜索 `Langfuse`，即可使用对应节点。
