# 提示词文件夹

提示词文件夹帮助你按逻辑分组管理提示词。随着提示词库不断增长，可以根据功能、团队、环境或适合你的工作流程的其他结构组织内容。

创建文件夹时，在提示词名称中加入斜杠（`/`）。界面会自动把以 `/` 结尾的每一段名称显示为文件夹，因此可以建立层级结构。

::: info 注意
通过 Python SDK 访问文件夹中的提示词，需要 `langfuse >= 3.0.2`。
:::

## 创建文件夹

在 Langfuse 界面中创建提示词时，在名称中加入 `/` 即可形成文件夹结构。
