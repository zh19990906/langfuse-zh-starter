# Pulse

Pulse 是 Langfuse 可观测性功能的一部分，帮助团队查看和理解追踪数据的变化趋势。由于官方 Pulse 页面包含产品专用组件与当前界面信息，静态中文版暂不复制其交互控件。

你可以先使用[可观测性概览](/official/observability/overview)、[指标与分析](/official/metrics/overview)和[官方 Pulse 文档](https://langfuse.com/docs/observability/features/pulse)了解实际功能。
