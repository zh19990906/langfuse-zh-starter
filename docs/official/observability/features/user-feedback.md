# 用户反馈

用户反馈可以帮助你了解 LLM 应用在真实使用场景下的效果。通过记录反馈数据，并把它与对应的 Trace 或 Observation 联系起来，可以分析哪些回答有帮助、哪些回答需要改进。

常见使用场景包括点赞/点踩、满意度评分、人工审核和对不良回答的反馈。
