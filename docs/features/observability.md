# 可观测性与追踪

来源：[Langfuse 官方文档：Observability](https://langfuse.com/docs/observability/overview)。以下是面向开发者的中文概念整理。

## 为什么需要 Trace？

LLM 应用的一次回答可能需要检索知识库、调用多个模型、使用工具并生成结果。只记录最后一段回答，很难确定问题发生在哪里。Langfuse 提供从整体请求到局部步骤的追踪视图。

## 常见概念

- **Trace（追踪）**：一次完整的请求、任务或工作流。
- **Observation（观察记录）**：工作流内部的步骤，例如模型生成、工具调用或普通函数执行。
- **Generation（模型生成）**：与 LLM 调用对应的观察记录。
- **Session（会话）**：把相关的多轮交互组织在一起。

## 常见分析场景

- 排查响应缓慢的步骤。
- 比较 Prompt 版本的 Token 成本。
- 找出某个用户会话中结果异常的模型调用。
- 将追踪数据和评估分数关联起来。

> [!TIP]
> 先在开发环境记录一条完整 Trace，再逐步增加用户标识、会话信息以及自定义元数据。
