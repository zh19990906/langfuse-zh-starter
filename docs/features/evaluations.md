# 评估与数据集

来源：[Langfuse 官方 Evaluation 概览](https://langfuse.com/docs/evaluation/overview)。

## 评估解决什么问题？

“模型输出看起来不错”不足以证明一次改动真的提升了质量。评估可以让团队用相对一致的方法衡量准确性、相关性、格式与用户体验。

## 常见评估方式

| 方式 | 适合场景 |
| --- | --- |
| 人工标注 | 需要领域判断的回答质量 |
| 用户反馈 | 收集真实用户的满意度信息 |
| 代码评估器 | 检验结构、规则与确定性条件 |
| LLM-as-a-Judge | 使用模型辅助评价开放式输出 |

## 数据集与实验

把代表性的输入及预期结果整理成数据集，使用不同 Prompt、模型或程序版本跑实验并比较输出与得分。

## 实践建议

先准备覆盖正常、边缘和失败案例的小型测试集；记录评估准则；把评估结果与 Traces 联系起来。模型评分本身也可能有偏差，重要判断仍需人工复核。
